# B21 素材模块实现说明

**对应 issue**：#47 / #67–#73  
**门禁**：`./scripts/dev-check.sh`（`gofumpt` / `goimports` / `golangci-lint` / `go test ./...` / `go build ./...`）

## 原理与背景

A1/A2 让用户粘贴英文、一句话或 URL。后端要把原文变成可复习的 `phrase_blocks`，客户端轮询直到 `refine_status=ready|failed`。语料 CRUD 已在 B10/B25，这里只做「创建素材 + 提炼入口」。

B16 `AIOrchestrator` 仍未独立成包。B18 和闪测已经用 `Completer` 缝（`drill.NewArkCompleter`）接 Ark。素材提炼走同一缝，不阻塞在 B16 master。

## 方案

独立包 `internal/materials`，表 `materials`（迁移 `0014_create_materials.sql`）。

| API | 行为 |
| --- | --- |
| `POST /api/v1/materials` | 202 `{material_id, refine_status:queued}`，后台 goroutine 调 `Refine`（LLM 30s 预算） |
| `GET /api/v1/materials/:id` | 轮询；跨用户 403；A4 `deleted_at` → 404 |

细节：

1. `kind`：`paste` / `sentence` / `url`。URL 不抓网页，`content` 写成 `[URL content placeholder]`（V1.5 再接真实 fetch）。
2. 正文上限 5000 bytes。
3. LLM 只收 JSON `{"blocks":[...]}`，写入走已有的 `corpus.SaveAcceptedBlocks`。
4. 状态机 CAS：`queued→processing→ready|failed`。非 queued 上的二次 `Refine` 是 no-op。`ready→processing` 返回 `ErrConflict`。
5. 0 个可用块：`ready` + `error_code=no_chunks_extracted`（合法空结果，客户端应停轮询，不要当失败重试）。
6. LLM 超时 / 调用失败 → `failed` + `llm_timeout`；JSON 解析失败 → `parse_error`；块写入失败 → `db_error`。
7. A4：`materials.PrivacyWiper` 挂进 `account.NewPrivacyService`。
8. 指标：`material_refine_timeout_total` / `material_refine_parse_error_total`（避免和 drill 的 `refine_timeout_total` 在同一 `/metrics` 重名）；`refine_status_transition_total{from,to}` 按 ticket 原名暴露。

OpenAPI 升到 `0.3.7`，增加 `createMaterial` / `getMaterial`。

## 缺口根因

原先没有素材表和提炼状态机。如果把原文直接塞进 `phrase_blocks`，客户端没有可 poll 的对象，也无法表达 queued/processing/failed。

B16 未 CLOSED 会让 A1/A2 一直挂着。闪测和 B18 已经证明 `Completer` 够接 Ark，不必再等 Orchestrator 包。

## 新方案理由

- **独立 `materials` 表**：提炼是异步状态机，客户端 poll 的是素材，不是某一条 chunk。
- **复用 Completer 而不是等 B16**：与 B18 同一决策，先打通 A1/A2；以后 Orchestrator 只换接线。
- **Create 立即 202 + 后台 Refine**：符合「提交后轮询」；单测仍可同步调 `Refine`。CAS 保证 goroutine 与显式 Refine 不会双写。
- **0 块标 ready 而不是 failed**：源文本合法但无可提炼块，重试 LLM 没有意义。
- **不改 0013**：B22 的 UP 已经在仓里。B21 只加 `0014`。

## 明确不做

- 真实 URL fetch / HTML 抽取
- 给 `phrase_blocks` 加 `material_id` 列（本批用 NULL `source_session_id` + 自然键 upsert）
- 改 drill 已有的 `refine_*` 指标名
- 独立 worker 队列（本批用进程内 goroutine；进程退出会丢掉 in-flight refine）
