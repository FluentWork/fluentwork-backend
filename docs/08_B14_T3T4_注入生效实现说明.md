## 二、关键时序

```text
Turn 1
  SendPCM → (可选等 ASR start) → session.update(注入) → commit
  → 当轮回复：一般无 INJECT_OK

Turn 2（若 Turn1 未命中）
  session.update(再次强调) → SendPCM → commit
  → 下轮回复：出现 INJECT_OK …
```

辅助：

- `collectTurn` 忽略上一轮残留的 `response.done`（需本轮已有 user progress + response progress）
- commit 后发送静音 keepalive，促使模型出文本/音频事件
