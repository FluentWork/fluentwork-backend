## 1. 回家后：查出今晚的 Mac IP

```bash
ipconfig getifaddr en0
# 若空，再试：
ipconfig getifaddr en1
```

应是 `192.168.x.x`。下面记为 `$HOST`。

iOS `AppEnvironment.local` 默认是 `192.168.2.15`。

| 今晚 `$HOST` | Xcode |
|---|---|
| 正好 `192.168.2.15` | 可不设 `LOCAL_HOST` |
| 其它 `192.168.x.x` | Scheme → Run → Environment Variables：`LOCAL_HOST` = `$HOST` |

不要填手机 IP。不要改 `AppEnvironment.swift` 里的默认值（机器相关，不能进 `main`）。

## 2. 启动 backend（Phase 1）

不要跑 `./scripts/dev-local.sh`（默认火山 + 写死 `192.168.2.15`）。

`.env.volc.local` 里有 `VOICE_GATEWAY_PROVIDER`。`dev-up.sh` **不会覆盖**已经 export 的变量：

```bash
cd fluentwork-backend
HOST=$(ipconfig getifaddr en0)
# en0 为空则改 en1

VOICE_GATEWAY_PROVIDER=dev-echo \
VOICE_DEV_ECHO_TEXT="let's ship it" \
VOICE_DEV_ECHO_TTS_MOCK=true \
./scripts/dev-up.sh --host "$HOST"
```

终端应出现：

```text
📡 WSS URL for iOS: ws://192.168.x.x:8081/v1/voice
   Set LOCAL_HOST=192.168.x.x in Xcode scheme for physical device testing.
```

健康检查（本机回环即可）：

```bash
curl -sf http://127.0.0.1:8080/healthz
curl -sf http://127.0.0.1:8081/healthz
```

再用 **Mac IP** 探一次，确认手机能走同一地址：

```bash
curl -sf "http://${HOST}:8080/healthz"
curl -sf "http://${HOST}:8081/healthz"
```

给 iOS 的地址：

- API：`http://$HOST:8080/api/v1`
- WSS：`ws://$HOST:8081/v1/voice`（以 `POST /sessions` 返回的 `wss_url` 为准）

停：跑 `dev-up.sh` 的那个终端 `Ctrl-C`。

## 4. 检查清单（记帧，不记听感）

每条留下：gateway 日志里的 `type` / `turn_id` / `outcome` / `log_id` + iOS 相位。

过滤：`process` 含 `voice-gateway`，或终端里 `ai.turn.end` / `client.turn.abort`。

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| 1 | 正常一轮 | 开口 → **松手** | v2 `ai.turn.end`：`turn_id`（如 `turn-1`）+ `outcome=ok` + `log_id`（DevEcho 为 `dev-echo`）。iOS 进评价等待；约 20s 无 badge 回 `waitingUser`，**不** `.failed` |
| 2 | abort | **按住不放约 60s**，不要松手 | 出站 `client.turn.abort` `outcome=timeout`；**无** `ai.turn.end`；**无** `error`；UI「本轮已超时」；WSS 仍在；可再开口 |
| 3 | 网关 B15 | 松手后 70s 无 `ai.turn.end` | `ai.turn.end outcome=timeout` → iOS `.failed("turn_timeout")`。**今晚跳过**（DevEcho 会立刻答） |
| 4 | 断网 | 会话中关 Wi-Fi / 飞行模式 | 旧 session 结束；回来是新 ticket + 新 `session_id`（不是恢复） |
| 5 | 锁屏 | 进后台 | iOS `forceClose` / `session.end` |
| 6 | 耳机插拔 | 录音或播放时插拔 | iOS 重配 tap；网关 **不**发 error |

abort ≠ B15：abort 是还按着说话；B15 是已经 `user.speech.end` 之后网关 `collectTurn` 超时。

TTS 可能是噪声或无声（mock decoder + DevEcho `ai.tts.*`）。只要帧对了就算 Phase 1 过。
