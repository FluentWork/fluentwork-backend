# FluentWork Backend 本地启动

**定位**：本仓本地开发的一键启动说明。产品与技术方案仍以 `fluentwork-meta` 为准。

## 默认启动（内存存储，无需 Docker）

需要：Go 1.26+。

```bash
./scripts/dev-up.sh
```

脚本会：

1. 读取 `.env`，没有则读取 `configs/app-server.env.example`
2. 清空 `MYSQL_DSN`，使用进程内账号存储
3. 启动 `app-server`
4. 等待 `/healthz`，并请求一次 `POST /api/v1/auth/guest`

默认地址：`http://127.0.0.1:8080`

停止：在该终端按 `Ctrl-C`。

## 可选：带 MySQL 8 启动

需要本机 Docker daemon 可用。

```bash
./scripts/dev-up.sh --mysql
```

这会通过 `deploy/docker-compose.yml` 拉起 MySQL，并按文件名顺序执行 `migrations/*.sql`。

停止 MySQL：

```bash
./scripts/dev-down.sh
```

## 常用接口

鉴权头：`Authorization: Bearer <access_token>`  
错误体：`{code, message, request_id}`  
API 前缀：`/api/v1`

```bash
# 健康检查
curl -sS http://127.0.0.1:8080/healthz
curl -sS http://127.0.0.1:8080/readyz

# 签发或复用游客身份（device_id 幂等）
curl -sS -H 'Content-Type: application/json' \
  -d '{"device_id":"device-1"}' \
  http://127.0.0.1:8080/api/v1/auth/guest

# 归并游客数据到已注册账号（需要非游客 access token）
curl -sS -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -d '{"device_id":"device-1"}' \
  http://127.0.0.1:8080/api/v1/account/merge
```

第一波 B1 不含完整邮箱/手机登录。merge 的注册账号由后续登录接口或测试夹具创建。

契约见 `api/openapi-v1.yaml`。

## 本地检查

```bash
./scripts/dev-check.sh
```

覆盖 `gofumpt`、`goimports`、`golangci-lint`、`go test ./...`、`go build ./...`。

## 配置

| 变量 | 说明 |
|---|---|
| `APP_ENV` | `development` 或 `production` |
| `HTTP_ADDR` | 监听地址，默认 `:8080` |
| `MYSQL_DSN` | 空则内存存储；生产环境必填 |
| `AUTH_JWT_SECRET` | 至少 32 字符；生产环境必须覆盖开发默认值 |
| `AUTH_ACCESS_TTL` | access token 有效期，默认 `2h` |
| `AUTH_REFRESH_TTL` | refresh token 有效期，默认 `720h` |

复制示例：

```bash
cp configs/app-server.env.example .env
```

`.env` 已被 gitignore，不要提交密钥。
