2. 读 `02_第二波开发范围与任务清单.md` - 了解边界

1. 检查 `问题分析与规划_2026-09-17.md` 的优先级
2. 参考核心架构文档（69/74/78）
3. 遵循 `05_B15` 的质量门禁

### 排查问题

1. 先读 `82_P0-1` 了解最新状态
2. 查找 `archive/implementation-details/` 中的相关实现
3. 使用 git blame 追溯代码变更

### 查找归档文档

```bash
# 列出所有归档文档
find docs/archive -name "*.md"

# 搜索特定主题
grep -r "duplex" docs/archive/

# 查看归档前的版本
git log --all --full-history -- docs/archive/
```
