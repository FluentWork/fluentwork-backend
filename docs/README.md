## 📖 如何使用本文档库

### 新加入开发者

1. 读 `01_本地启动.md` - 搭建环境
2. 读 `02_第二波开发范围与任务清单.md` - 了解边界
3. 读 `问题分析与规划_2026-09-17.md` - 了解当前状态

### 开发新功能

1. 检查 `问题分析与规划_2026-09-17.md` 的优先级
2. 参考核心架构文档（69/74/78）
3. 遵循 `05_B15` 的质量门禁

### 排查问题

1. 先读 `82_P0-1` 了解最新状态
2. 查找 `archive/implementation-details/` 中的相关实现
3. 使用 git blame 追溯代码变更

### 查找归档文档

```bash
# 列出所有归档文档
find docs/archive -name "*.md"

# 搜索特定主题
grep -r "duplex" docs/archive/

# 查看归档前的版本
git log --all --full-history -- docs/archive/
```

## 🎯 文档维护原则

### 保留在根目录的文档

- ✅ 当前开发正在参考
- ✅ 架构决策记录（ADR）
- ✅ 未来迭代需要的设计
- ✅ 运维必需的操作指南

### 应归档的文档

- ❌ 已完成的 POC/实验
- ❌ 过时的问题快照
- ❌ 底层实现细节（代码是真相）
- ❌ 已被替代的方案

### 文档命名规范

- 新文档使用递增编号：`83_`, `84_`, ...
- 标题简洁明确，包含关键词
- 日期后缀用于快照：`_2026-09-17`
