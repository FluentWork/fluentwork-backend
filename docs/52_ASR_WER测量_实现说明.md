# ASR WER 测量

**日期**：2026-09-11
**状态**：测量已完成，结论见 §4。门禁见 §6。
**对应**：meta `77_` **P1-4** · 执行计划**步 5**（决定要不要从 duplex 迁向分解流水线）

## 1. 样本与来源

**谁录的**：一位中文母语者（项目 owner），照 `internal/voicepoc/testdata/asr_wer_samples.json` 的 30 条文本朗读。
**怎么录的**：手机录音（m4a），安静环境，自然语速 —— 未刻意放慢或模仿美式发音（刻意标准化的语料测不出真实口音）。
**处理**：`ffmpeg -ar 16000 -ac 1 -c:a pcm_s16le`，30 条全部成功转换。

**样本不是随便挑的**：每条标注了它考的音素陷阱（`th` / `r-l` / `v-w` / `final-consonant` / `cluster` / `ed-suffix` / `number`），所以结果可以**按陷阱切片**。这是本集合存在的意义 —— 一个总数字给不出决策需要的信息。

**录音文件映射曾整体错位一位**（`新录音 K.m4a` → `wer-(K+1)`，`Wer01.m4a` → `wer-01`）。用 3 次探针（首、中、尾）转录后比对参考文本确认，未凭文件名猜测 —— 映射错一位会让**每一条**都对着错误的参考打分，而结果看起来只是"WER 很高"。

## 2. 结果

```
总体: WER 14.7%    S=30  D=0  I=9    N=266
```

**`D = 0`。一次"没听见"都没有。**

### 按音素陷阱

| 陷阱 | n | WER | S | D | I |
|---|---|---|---|---|---|
| number | 1 | 25.0% | 2 | 0 | 0 |
| ed-suffix | 3 | 24.1% | 5 | 0 | 2 |
| **r-l** | 15 | **23.7%** | 24 | 0 | 7 |
| th | 17 | 15.0% | 16 | 0 | 7 |
| final-consonant | 11 | 9.7% | 8 | 0 | 1 |
| cluster | 13 | 8.3% | 8 | 0 | 2 |
| v-w | 3 | 7.7% | 1 | 0 | 1 |

（n 之和 > 30：一条样本常考多个陷阱。）

### 其中约四分之一不是识别错误

39 个错误里，**10 个是纯格式差异** —— 识别器听对了词，只是写法与参考不同：

| 转出 | 参考 |
|---|---|
| `3:30` | three thirty |
| `3 years` | three years |
| `I have been` | I've been |
| `I will` | I'll |
| `there is` | there's |
| `clean up` | cleanup |
| `back end` | backend |

**归一化（数字读法 + 缩写展开）后：29 处 / 10.4%。**

> **这两个数都要报。** 只报 14.7% 会让后续每一次运行都偏悲观 3-4 个百分点，而总会有人拿它去做决定。评分器目前**不做**归一化（§5），所以工具默认输出的是偏悲观的那个。

## 3. 我预测错的地方

`wer.go` 里我写的注释说：

> 删除 = 没听见（词尾脱落、吞音）

**实测 `final-consonant` 是 9.7%，D = 0。** 模型**没有**漏掉词尾。

真实的失败模式是**替换**：把词听成另一个**发音相近**的词，而且语义连贯：

```
blocked → broke      pair → peel        Sarah → share
rebase  → replace    branch → brunch    cache → catch
retry   → try        backoff → back     failing → falling
```

**这不是切音/端点问题，是声学模型在相似音上的混淆。** 我原来的心智模型（"中式口音 = 吞音"）是错的；实际是**对比音素**（r/l、θ/ð）在出错。

## 4. 结论：**不迁移到分解流水线**

计划里这一步的意义是"决定要不要从 duplex 迁向分解流水线"。**结论是不迁。** 三条理由：

1. **失败模式不是分解流水线能修的。** 分解流水线的结构性优势在**独立的 VAD/端点 + 专用 ASR**，它解决的是**丢词、切分错误、时延**。而我们的 **D = 0** —— 切分没有失败。

2. **替换会跟着 ASR 模型走，不会跟着管线走。** 换管线但用同一家 ASR，同样的 r/l 混淆会原样保留。**换管线不改变声学模型。** 真要改善替换，那是**换 ASR 供应商**的问题，不是架构问题。

3. **这个数字对产品是可用的。** 归一化后 10.4%，且转出的词**语义连贯** —— 对回顾、徽章这些下游功能足够。

### 这个数字真正指向的行动

| 项 | 说明 |
|---|---|
| **`r-l` 23.7%（n=15，最大类）** | 最好的单点目标。但这是**产品机会**（针对 l/r 最小对立对的发音反馈），不是基础设施问题 |
| **评分器需要归一化** | 见 §5。否则每次运行都会偏悲观 |
| **不换供应商就到此为止** | 若将来要压低替换，先测**另一家 ASR**，而不是先改架构 |

## 5. 本票不做

- **不给评分器加归一化**：归一化的口径（哪些算等价）本身会影响数字，需要单独定义并留档，不能顺手改。**在那之前，工具输出的数字比实际偏悲观 3-4 个百分点**，这一点必须和数字一起说。
- **不换 ASR 供应商**：本票只测量。要不要换是下一步的决策。
- **不改 duplex 架构**：见 §4。
