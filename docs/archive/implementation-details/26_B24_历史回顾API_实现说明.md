# B24 历史回顾 API 实现说明

**对应 issue**：#50 / #90–#93  
**代码**：`d90d4e4` `feat(sessionhistory): add B24 session list and detail APIs`  
**门禁**：`go test ./internal/sessionhistory/... ./internal/session/... ./internal/httpserver/...` 与全仓 `go test ./...`

## 原理与背景

iOS 历史回顾（I19）需要「我的会话列表」和「单会话详情」。当时 HTTP 面只有：

- `POST /sessions` 创建
- `GET /sessions/:id/review` 轮询 B6 炼化稿
- `POST /sessions/:id/messages` 文本降级

没有按用户列出 `practice_sessions`，也没有把 transcript + 评价汇总进同一份详情。B18（per-utterance eval）和 B22（A4 `deleted_at`）合进 `main` 之后，这张票的阻塞解除。

列表必须稳定翻页：同一毫秒内多条会话不能漂移或重复。详情必须尊重 A4 软删，并嵌入 B18 三维评分，而不是把 B6 的整份 `review_json` 再暴露一遍。

## 方案

独立包 `internal/sessionhistory`，只读复用 `session.Store`，不另起表。

| API | 行为 |
| --- | --- |
| `GET /api/v1/sessions?cursor=&size=` | 当前用户、未删除、`created_at DESC, id DESC`；默认 size=20；`size` 越界（含 200）回落到 20 |
| `GET /api/v1/sessions/:id` | 详情：utterances + 可选 B18 `review`；跨用户 403；A4 已删 404 |

Cursor 是 `{"started_at","id"}` 的 JSON，再 `base64.URLEncoding`。表没有 `started_at` 列，JSON 的 `started_at` 映射 `practice_sessions.created_at`。下一页条件：`created_at < cursor`，或时间相同且 `id < cursor.id`（与 DESC 排序一致）。

详情里的 `review`：

- `session.finished` job = failed → `{status:"failed", score:0}`
- `status=reviewed` 且 B18 `Summary.Complete` → `{status:"ready", score, dims, suggestions}`
- 否则省略（pending）

`materials` 在 B21 落地前固定返回 `[]`，避免 iOS 解空值。

## 缺口根因

MySQL `scanSession` 原先**故意不读** `deleted_at`（注释写明，`sessionColumnCount=9`）。A4 软删只 UPDATE 该列，GetSession 仍返回会话且 `DeletedAt==nil`。历史详情会把已删会话当活数据。

根因：A4 加列时为少改 sqlmock 扫描 arity，把软删列排除在主扫描路径外。MemoryStore 一直有 `DeletedAt`，单测过了，MySQL 路径是盲区。

## 新方案理由

1. **把 `deleted_at` 纳入 `scanSession`**（10 列），List 用 `deleted_at IS NULL`。详情看到已删就 404；撤销后同一 Get 再 200。不另做「历史专用 Get」，避免两套会话语义。
2. **独立 package** 而不是塞进 `session.Handler`：创建/激活/review worker 与只读历史翻页的变更速率不同，Gin 路由也更好拆 `GET /sessions` vs `POST /sessions`。
3. **跨用户 403 而不是 404**：与 `GetReview` 的「隐藏存在」不同，B24 验收写明 403，按 ticket。
4. **详情 embed B18 而不是 B6 `review_json`**：列表/回顾页要的是三维分和短建议；完整炼化稿仍走 `GET /sessions/:id/review`。

## 明确不做

- `since` / `until` / `material_id` 筛选（V1.5）
- 把 B21 materials 行嵌进详情（只留空数组）
- 改 B6 review 轮询契约
