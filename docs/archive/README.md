# 归档文档说明

本目录存放已完成、已过时或历史参考价值的文档。

## 归档原则

1. **已完成的 POC/实验**: B14 注入 POC、I20 修复计划等
2. **已冻结的协议演进**: WSS 协议迭代过程文档
3. **已替代的实现**: 被新方案替代的旧实现说明
4. **历史快照**: WER 报告、问题清单收口状态等

## 目录结构

- `b14-poc/`: B14 注入 POC 相关文档（已完成）
- `i20-fixes/`: I20 修复计划及相关实现（已完成）
- `wss-protocol-evolution/`: WSS 协议演进过程文档（已冻结）
- `legacy-implementations/`: 已废弃的实现说明

## 活跃文档

保留在 `docs/` 根目录的文档应满足以下条件之一：
1. 当前开发正在参考
2. 未来迭代需要参考的架构决策
3. 运维和故障排查必需

## 查找归档文档

使用 git 历史查看归档前的文档：
```bash
git log --all --full-history -- docs/archive/
git show <commit>:<path>
```
