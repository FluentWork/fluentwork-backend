## 二、方法

每个 trial：

1. `SendPCM` → `commit`（≈ VAD-stop）  
2. 等待 delay ∈ {200,400,600,800,1000}ms  
3. `session.update`（要求 `INJECT_OK`）  
4. 收集当轮回复 → `AffectedSameTurn`  
5. 若未命中：再 update + 第二段 PCM → `AffectedNextTurn`  

`SummarizeTrials`：无同轮命中但有下轮命中 → 直接档位 ②。
